Root Cause Analysis (RCA) Verified by Kernel Team

Exhaustion of ephemeral port allocation during BGP route flapping event at 09:30 EST. Legacy keepalive timer (15s) failed to reap dead state tables in FreeBSD kernel module ip_fw_sockopt.c, compounding memory buffer leaks across active tunnel descriptors.
